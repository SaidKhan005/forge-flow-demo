`docs/_indices/` contains only:

- The forward-roadmap doc (currently `NEXT_WAVE_PLAN.md`).
- The current wave's slice ledger (currently `WAVE_EXECUTION_LEDGER.md`,
  marked CLOSED until the next wave opens its own).

  `CODEX_HANDOFF_PROMPT.md`) — paste-ready prompts encoding the
  executor-agnostic workflow.

and retire here when the wave closes.
