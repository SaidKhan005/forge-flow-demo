## TL;DR

Locks the `SinkBusinessDateProjector` helper API surface AND applies it to the Square POS Postgres sink as the exemplar before Slice 7b.2 mechanically migrates the remaining 19 vendor sinks. Closes Gap 46 (sub-hour cutoff truncation) AND Gap 47 (operator → org_unit → location hierarchy bypass) for Square in one move per the operator-locked decision in `docs/_audits/per_daypart_v1/slice_7b_research_2026_05_15.md` (option b, sub-option b1, fallback hour 4).

The helper at `lib/services/integration/sink_business_date_projector.dart` wraps the canonical `BusinessTimingProfilesRepository.listCandidateProfilesForLocation` → `BusinessTimingProfileResolver.resolve` → `BusinessDateResolver.resolve` chain that already runs in production for the open-shift snapshot projector (`lib/services/integration/open_shift_snapshot_projector.dart:32-94`). It accepts a `(operatorId, locationId, restaurantTimezone, instantUtc)` tuple and returns a UTC-midnight `DateTime` that callers format to 'YYYY-MM-DD' for the SQL `::date` cast.

The Square sink at `lib/infrastructure/persistence/postgres/square_pos_postgres_sink.dart` no longer reads `locations.business_day_rollover_hour`. The location-row SELECT now returns `timezone` only (line 188-201); the cutoff is resolved through the helper (line 207-216). The Square sink is the FIRST of 20 — the other 19 stay on the legacy code path; Slice 7b.2 mechanically migrates them.

The deprecation migration `db/migrations/202605161500_per_daypart_v1_deprecate_locations_rollover_hour.sql` adds a `COMMENT ON COLUMN` only — no DDL change, no data change. The column drop is deferred to a follow-up after a deprecation cycle (sub-decision locked).

`dart analyze --fatal-infos` clean on all four touched files. `flutter test` 27/27 pass (7 helper unit tests + 20 Square sink tests including 4 new I.1–I.4 regression tests). Migration drift scanner exit 0 (one expected side-effect: `scripts/postgres_staging_setup.ps1` cutoff line auto-bumped). Migration cutoff lint clean.

Hard stops respected: no other 19 sinks touched, no `--no-verify`, no merge, no tracker / ledger / plan / brief / index doc edits. Operator decisions honored: option (b), sub-option (b1) (SQL trigger stays as legacy backup), fallback hour `'04:00'`, column deprecated NOT dropped.
