## Task 2 — `AuthEventsAuditRepository.insertEvent()` call sites

`AuthEventsAuditRepository.insertEvent` is declared at
[auth_events_audit_repository.dart:57](../../lib/infrastructure/persistence/postgres/repositories/auth_events_audit_repository.dart:57).
The repository sets `actor_kind` default `'user'` at the parameter
level ([auth_events_audit_repository.dart:62](../../lib/infrastructure/persistence/postgres/repositories/auth_events_audit_repository.dart:62)),
threads `actor_user_id`, `actor_service_principal_id`, and `event_type`
through to the SQL bind ([auth_events_audit_repository.dart:78-102](../../lib/infrastructure/persistence/postgres/repositories/auth_events_audit_repository.dart:78)).

Per the audit attribution contract
([audit_attribution_contract.md:46-65](../contracts/audit_attribution_contract.md:46)),
every row MUST satisfy:

- `actor_kind` ∈ {`user`, `service`} (closed set; the repository layer
  is the contract enforcer until a future migration tightens the
  schema CHECK).
- For `actor_kind = 'user'`: `actor_user_id` set, `actor_service_principal_id` NULL.
- For `actor_kind = 'service'`: `actor_service_principal_id` set, `actor_user_id` NULL.
- `event_type` is `NOT NULL` at the schema level
  ([auth_events_audit_repository.dart:12](../../lib/infrastructure/persistence/postgres/repositories/auth_events_audit_repository.dart:12)).
  (The audit prompt names this column `event_kind`; the table column is
  `event_type` — referenced by both reads.)

## Task 4 — Team tab visibility + per-action gating

### Tab visibility

[settings_screen.dart:224-227](../../lib/screens/settings_screen.dart:224)
gates the Team tab on
`TeamScopeVisibilityPolicy.canSeeTeamNav(effectiveTeamActor)`.
The policy at
[team_scope_visibility_policy.dart:67-77](../../lib/services/team/team_scope_visibility_policy.dart:67)
requires:

1. `actor.actorPermissions.contains('team.users.view')`
   ([team_scope_visibility_policy.dart:68](../../lib/services/team/team_scope_visibility_policy.dart:68))
2. AND admin-tier
   (`super_admin` / `ff_support` at
   [team_scope_visibility_policy.dart:114-117](../../lib/services/team/team_scope_visibility_policy.dart:114))
   OR `operator_owner`
   ([team_scope_visibility_policy.dart:70](../../lib/services/team/team_scope_visibility_policy.dart:70))
   OR `operator_manager` with at least one assigned location
   ([team_scope_visibility_policy.dart:71-74](../../lib/services/team/team_scope_visibility_policy.dart:71)).
