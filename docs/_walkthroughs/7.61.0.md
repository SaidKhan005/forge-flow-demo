## Demo-mode walkthrough

`7.61.0` is audit-only and does not change what the operator sees on
screen. The walkthrough below confirms the driver keys flowing through
the demo paths match the catalog and storage forms the contract
pins; no UX assertion changes from the `7.58.UX.5` baseline.

### Step 1 — Launch the operator app in demo mode

`lib/main_forgeflow.dart` boots the operator shell with
`MockReplayDataSeed` attached. Default business date is `2026-03-27`
(Friday in W13). The replay seed at
`lib/data/mock_integration_replay_seed.dart` mints closed
`ShiftRecord` rows via `lever.toUpperCase()` (line 364) and open
rows via the `'ON_MODEL'` sentinel (line 314), per R-PROD-2 and
R-PROD-3. WTD `WeekData.primaryLeverId` is computed direct from
`LaborModel.determineLever` and remains lowercase (line 468).

### Step 2 — Variance > This Week (catalog + presentation re-check)

Tap **Variance**. The PRIMARY DRIVER section reads
`weekData.primaryLeverId` (lowercase per R-PROD-5) and resolves it
through `LeverCards.lookup` per `7.58.UX.5`. The card body matches
the `LeverCardData` whose `id` is exactly `weekData.primaryLeverId`
(R-CONS-7). No upper-snake leakage.

### Step 3 — Variance > This Week > FULL WEEK PROJECTION (storage-form re-check)

Scroll to FULL WEEK PROJECTION. Tap **Mon** → expand: the closed
lunch and dinner detail panels each render `_LeverBadge` populated
from `LeverCardData.metric` (per `7.58.UX.5` F-7); the row driver
text comes from `s.normalizedLeverId.replaceAll('_', ' ')` (lowercase,
not the upper-snake storage form), confirming R-STOR-3 in practice.
Open rows show `'Not yet available'` per `7.58.5` row purity.

### Step 4 — Variance > Learn (consumer re-check)

Tap **Learn**. The PRIMARY LEAK card reads
`LearnTeachingSummary.primaryLeakId` (lowercase, downstream of
`HistoryTeachingAnalyzer.summarize`'s `mostCommonLeakId`). Today this
card may render `'covers down'` even when no leak exists in history
— that's the F-2 overclaim documented in the plan doc and queued for
`7.61.2`. The contract pins R-CONS-2 / R-CONS-9 to forbid this; the
test case for the empty-leak path will land with `7.61.2` once the
default flips.

### Step 5 — Baseline Manager > day detail (cross-table re-check)

Tap **Baseline Manager** → any closed-shift day → expand: the LEVER
chip renders `leverLabel(candidate.primaryLeverId)` where
`candidate.primaryLeverId` is `shift.normalizedLeverId` (lowercase per
R-CONS-6). The catalog round-trip
`LeverCards.all.cast<LeverCardData?>().firstWhere(... orElse: () => null)`
at `baseline_manager_helpers.dart:45-48, :58-62` is functionally
equivalent to `LeverCards.lookup` (returns null on miss); not banned,
not flagged.
