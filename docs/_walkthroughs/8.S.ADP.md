# 8.S.ADP Walkthrough — ADP Workforce Now / Workforce Manager labor adapter (lifecycle = documented)

**Slice:** 8.S.ADP (Phase 8.S — engineer-all-17 Wave B; ADP labor adapter; partnership-gated; module disambiguation)
**Mode:** `kDemoMode = true` (operator app, deterministic seed)
**Date:** 2026-05-04
**Lifecycle target at slice close:** `VendorLifecycle.documented`

This slice ships the ADP labor adapter at lifecycle = `documented`
per the engineer-all-17 doctrine
(`memory/project_phase_8_engineer_all_17_doctrine.md`). ADP carries
the **longest partnership lead time** in the wave (12-24 weeks for
the ADP Marketplace Developer Participation Agreement) and the
**load-bearing module-disambiguation pattern**: only Workforce Now
(WFN) and Workforce Manager (WFM) are supported; ADP RUN is refused
at connect time with the friendly copy locked in
`docs/phases/phase_8/vendor_master_list.md`. Engineering proceeds
against the published shapes from the developer-portal API catalog
(Time Events / Team Time Cards / Time Work Schedules / Work
Assignments / Workers) so the moment ADP issues partner credentials,
only the small `8.S.ADP.live.sandbox` slice remains. EVERY field-
mapping assumption is captured as a `verify_in_live_sandbox: true`
row in `documentedPerAdpV1FieldMapping` so the live diff is bounded.
Live HTTP is deferred to `8.S.ADP.live.sandbox` /
`8.S.ADP.live.prod` (Wave D, partnership-gated).

The slice respects every Hard Promise from `CLAUDE.md`:

1. Pure transport — the adapter writes existing canonical labor
   tables only; no business logic in `lib/services/*` is touched.
2. Demo-mode persists — the same vendor-picker chrome renders in
   `kDemoMode = true` and `kDemoMode = false`, and the connect flow
   tells the operator the connection will flip them out of demo (when
   the lifecycle promotes to `production_credentialed`).
3. No app-logic changes before `7.58` — this slice adds a vendor
   adapter; metric formulas are untouched.
4. Per-operator isolation — every gateway call routes through
   `OperatorScopedRepository.withTenant(operatorId, locationId, ...)`.
5. Modular Adaptive Agentic RAG — n/a for this surface.
6. Recommendations not commands — n/a (labor data inflow only).
7. F&F holds provider keys server-side — the partner-issued OAuth
   client_id / client_secret / mTLS cert pair will live in Cloud Run
   env at `8.S.ADP.live.prod` per V1 lean cut 2 (KMS post-launch);
   the documented slice runs entirely against the test transport.
8. AI infra is general-purpose — n/a (labor adapter, not AI).
9. AI cost metering — n/a.
10. Backend phase ships operator-facing UX before phase close — the
    Vendor Connections widget already renders the "Coming soon" pill
    for `documented`-lifecycle vendors; this slice plugs ADP into
    that surface with the three-module picker disambiguation
    described below.

  `worker.position.position_title` to WFM

### `lib/integrations/labor/adp_webhook_signature_verifier.dart` (NEW)

- `class AdpWebhookSignatureVerifier implements VendorWebhookSignatureVerifier`
  — HMAC-SHA256 over the raw body, base64-encoded,
  `ADP-Signature` header (every behavior assumed; flagged for
  verification in `*.live.sandbox`). Constant-time compare via the
  framework's `constantTimeBytesEquals`.
- Optional `ADP-Signature-Timestamp` (Unix epoch seconds) populates
  `WebhookSignatureVerification.timestamp` so the framework's 24h
  replay ceiling enforces against it; when the vendor does not
  bind a timestamp into the signed payload the verifier returns
  null and the idempotency UNIQUE on
  `(vendor_id, operator_id, vendor_event_id)` is the duplicate-
  write defense for legitimate retries.

### Step 7 — Engineering anchor: forged signature → 403

### Step 8 — Engineering anchor: malformed payload drop

**Expected:** No partial-write flag (banned per V1 lean cut 2). The
adapter either writes a clean canonical fact or refuses.

### Step 11 — Engineering anchor: disconnect / reconnect watermark preservation

```

            same watermark visible to next poll
```

**Expected:** `postReconnectWatermark.lastModifiedSeen ==
preDisconnectWatermark.lastModifiedSeen`. Pinned in "Test 5 — full
