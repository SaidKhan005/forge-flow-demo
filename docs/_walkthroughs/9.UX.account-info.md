# 9.UX Account Info Walkthrough

Date: 2026-04-30

Scope: Settings -> Account -> My info, read-only self profile.

## Trace

1. Launch the authenticated ForgeFlow build with the proxy base URI configured.
2. Sign in as a demo or staging operator.
3. Open Settings -> Account.
4. Confirm the My info card appears above password and sign-out actions.
5. Confirm the card shows friendly labels only:
   - Display name
   - Email
   - Account status
   - Current location
   - Role labels
   - MFA enabled state
   - Last login, last active, and password updated timestamps when present
6. Confirm a lower-permission user keeps the same Account layout and can see My info without the Team tab.
7. Confirm Team remains hidden when the actor lacks Team visibility permissions.
8. Confirm error, loading, and fallback states do not show raw IDs, permission keys, policy names, stack traces, Firebase internals, HTTP status jargon, or table names.

## Route Evidence

The app-side gateway calls `GET /v1/auth/account` with only the verified Firebase bearer token. The route derives `userId`, `operatorId`, and `locationId` from the existing proxy auth guard and does not accept a `user_id` query or body parameter.

The response shape is friendly JSON only:

```json
{
  "display_name": "Jane Operator",
  "email": "jane@example.test",
  "status_label": "Active",
  "location_label": "Downtown",
  "role_labels": ["Kitchen Lead"],
  "mfa_enabled": true,
  "last_login_at": "2026-04-29T12:00:00.000Z",
  "last_active_at": "2026-04-29T12:15:00.000Z",
  "password_updated_at": "2026-04-20T09:00:00.000Z"
}
```

No raw user, operator, location, role, permission, policy, Firebase, or storage identifiers are part of the UI contract.

## Operational Note

The remaining completion dependency is deployment/runtime wiring, not app code. If the authenticated app points at an older proxy that does not include `GET /v1/auth/account`, Settings -> Account will render safe fallback account info with a temporary-unavailable notice. Full backend profile data requires the running proxy to include this branch's `account_info: postgres` production binding and `/v1/auth/account` route.
